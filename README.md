# Customer Shopping Behavior Analysis

A data analytics project analyzing customer shopping behavior using **Python, SQL, and Power BI**.

## 🛠️ Tools Used

* Python
* Pandas
* SQL
* Power BI
* Google Colab

## 🔄 Data Processing

The project uses Pandas to:

* Load the customer shopping dataset
* Check dataset information and summary statistics
* Check duplicate records and missing values
* Fill missing review ratings using the **median rating of the product category**
* Rename columns using snake_case
* Create an `age_group` column
* Convert purchase frequency into `purchase_frequency_days`
* Remove the redundant `promo_code_used` column
* Export the processed dataset as a CSV file

## 🗄️ SQL Analysis

The processed data is used for SQL-based business analysis, including customer spending, product ratings, discounts, subscriptions, repeat purchases, and revenue by age group.

## 📊 Power BI

The processed dataset is used to create a Power BI dashboard for analyzing customer shopping behavior.
